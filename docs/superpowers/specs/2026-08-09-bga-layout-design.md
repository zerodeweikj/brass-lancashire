# 游戏主界面 UI 重设计 —— BGA 版式

> 状态：对齐稿，待视觉验收后实施  
> 依据：用户提供的 BGA「领国者」截图（action bar 置顶 + 手牌在版图左上角横排面板 + 玩家面板右侧堆叠）  
> **美术约束**：排版学 BGA，**但图全部用项目自有素材**（自有版图底图、卡牌图、面板图），不套 BGA 美术。

## 1. 总体布局

采用 **BGA tableview 式** 布局，全屏固定分层：

```
┌──────────────────────────────────────────────────────────────┐
│  顶部行动栏（固定 56px）                                        │
│  [建造产业] [建造连接] [双手牌建造] [售卖棉花] [发展] [贷款] [跳过]  │
├──────────────────────────────────────────┬───────────────────┤
│           游戏版图区（camera view）          │   玩家面板列       │
│            可拖拽/缩放/WASD移动              │   红              │
│   ┌─────────────────────────────┐          │   白              │
│   │ 手牌 (N)  [卡][卡][卡][卡].. │ ← 嵌入左上 │   黄              │
│   └─────────────────────────────┘          │   紫              │
│                                           │                   │
└──────────────────────────────────────────┴───────────────────┘
```

- 版图区：中央主视觉，Phaser camera 控制。
- 玩家面板列：右侧固定宽度 320px，4 个玩家面板**垂直堆叠**，顺序固定 **红 → 白 → 黄 → 紫**。
- 手牌区：**嵌入版图区左上角**的一个小面板，标题「手牌 (N)」，卡牌**水平横排、平铺、正面朝上**，**常驻显示、不做扇形、不做收起**。
- 顶部行动栏：像 BGA 截图红圈处一样，放置本局所有可选行动按钮。
- 美术：沿用项目现有的版图底图 / 卡牌图 / 玩家面板底图等自有素材。

## 2. 顶部行动栏

按钮顺序从左到右：

1. **建造产业板块** — 进入「选择弃牌 → 高亮合法槽位 → 点击地图建造」流程。
2. **建造连接板块** — 选择弃牌/支付 → 高亮合法连结点 → 点击地图放置。
3. **双手牌建造** — 作为一次行动，弃 2 张牌当作 1 张城市牌使用。
4. **售卖棉花** — 选择要卖的棉花厂 → 消耗市场/海外需求。
5. **发展** — 从个人 mat 移除低级板块，升级高级板块。
6. **贷款** — 执行贷款，收入轨后退、获得现金。
7. **跳过** — 结束本回合行动。

样式：深色底 + 金色/蓝色描边，当前可执行行动高亮，不可执行置灰。

## 3. 手牌区（嵌入版图左上角，水平横排）

- 只显示**当前玩家**自己的手牌，对手手牌不显示（与 `view_for` 隐私一致）。
- **嵌入游戏版图区左上角**，是一个独立小面板，标题 **「手牌 (N)」**（N = 当前手牌数）。
- 卡牌**水平横排、平铺、正面朝上**，**不做扇形、不做旋转、不做收起/展开按钮**，始终可见（按用户确认：废止之前"左侧扇形"与"底部收起"两个提案，照 BGA 截图横排样式）。
- 卡牌在需要弃牌时被选中（建造/连接/双手牌/贷款等流程），选中态加高亮边框。
- 鼠标悬停卡牌放大显示完整卡面。
- 美术用项目自有卡牌图素材。

## 4. 右侧玩家面板列

4 个面板固定顺序 **红、白、黄、紫**，垂直堆叠：

- 每个面板高度约 160–180px。
- 顶部一行：玩家色块/头像 + 名称 + 金钱/收入位置指示。
- 主体：个人 mat，显示该玩家剩余产业板块库存（棉、港、船、铁、煤）。
- 规则沿用之前：
  - 只有 `stock > 0` 的板块才绘制，数量 0 不显示，露出底图。
  - 鼠标悬停板块时，光标旁显示 **「棉花厂1 剩余 3」** 提示，数量 0 不触发悬停。
  - 不显示静态「已建/库存」文字。
- 当前行动玩家面板加高亮边框。

## 5. 建造流程（纠正后的交互）

1. 玩家点击顶部 **「建造产业板块」** 按钮。
2. 系统提示：**请选择要弃置的牌**（手牌区常驻在左侧，此时高亮可选卡牌）。
3. 玩家点击 1 张手牌：
   - 若为**产业牌**：只高亮该产业的所有合法地图槽位。
   - 若为**城市牌**：检查该城市所有空产业槽位 → 这些空槽位所属产业即为可建造产业，高亮对应地图槽位。
4. 玩家点击高亮的地图槽位 → 前端发送 `POST /api/rooms/{id}/actions/build`（含 `cardIds`, `location`, `slotIndex`, `industry`）。
5. 后端校验沿用 `engine/actions.py` 的 `do_build` / `_card_allows_build`。
6. 建造成功后刷新版图与个人面板。

**双手牌建造**：点击 **「双手牌建造」** → 选择 2 张手牌 → 视为 1 张城市牌 → 后续流程同上。

## 6. 其他行动流程

- **建造连接**：点击按钮 → 选择 1 张手牌 → 高亮合法连结 → 点击地图放置。
- **售卖棉花**：点击按钮 → 选择要出售的棉花厂 → 系统自动消耗市场需求/海外需求。
- **发展**：点击按钮 → 选择要从 mat 移除的低级板块 → 升级对应高级板块。
- **贷款**：点击按钮 → 确认 → 后端执行。
- **跳过**：点击按钮 → 确认 → 后端执行 `pass`。

## 7. 版图显示（静态适配，无相机控制）

- BGA 版式下**不需要**游戏内相机控制：不提供 WASD / 方向键平移，也不提供滚轮/缩放。
- 版图整张**缩放适配**中间主区域一屏显示；玩家若想放大看细节用浏览器原生 **CTRL + 滚轮**。
- `web/src/utils/cameraControl.js` 的 WASD/方向键逻辑删除；不再绑定键盘抢键。

## 8. 需要删除/替换的旧实现

- 删除 `web/src/scenes/PlayerPanelsScene.js`。
- 删除 `?scene=panels` 路由与入口（含 `web/src/main.js` 中的注册与跳过 App 的逻辑）。
- 将单面板渲染逻辑抽象为可复用组件，供 GameScene 右侧列使用。
- `web/src/utils/cameraControl.js` 仅保留（如有）缩放适配，删除键盘平移。

## 9. 实施顺序

1. 用 HTML/CSS 制作静态 mockup 供视觉验收。（已完成）
2. 删除 `PlayerPanelsScene.js` 与 `?scene=panels`，移除相机键盘控制。
3. 重构 `GameScene`：右侧固定玩家面板列 + 版图左上手牌横排面板 + 顶部行动栏 + 静态适配版图。
4. 实现行动按钮状态与点击流程。
5. 实现弃牌 → 高亮合法槽位 → 点击建造的完整流程。
6. 实现其他行动按钮（连接、双手牌、售卖、发展、贷款、跳过）。
7. 联调测试。
